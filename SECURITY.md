# Security Policy

## Reporting Security Vulnerabilities

The Serendib HAB team takes security and mission safety seriously. If you discover a vulnerability or security issue in any Serendib HAB software, firmware, or infrastructure, please disclose it responsibly.

### How to Report

Please do **not** file public issues for security vulnerabilities. Instead, send an email to:

* **Email**: [serendib@sedssl.org](mailto:serendib@sedssl.org)

Include relevant technical details, reproduction steps, and potential impact. We will acknowledge receipt within 48 to 72 hours and work on a fix promptly.
